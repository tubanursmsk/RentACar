═══════════════════════════════════════════════════
PROJE KAPSAMI
═══════════════════════════════════════════════════

Çoklu şube (İzmir, Ankara, İstanbul) yapınıza uygun, 10-100+ araçlık
filo yönetimi yapabilen, kullanıcıların online rezervasyon ve ödeme
gerçekleştirebileceği, kurumsal düzeyde bir rent-a-car platformu.

────────────────────────────────────────────────
A. KULLANICI (MÜŞTERİ) TARAFI
────────────────────────────────────────────────

• Modern, mobil uyumlu, hızlı web arayüzü (Avis benzeri profesyonel
  görünüm, ancak firmanıza özgü tasarım)
• Türkçe + İngilizce çoklu dil desteği
• Anasayfa: Hero alanı + öne çıkan araçlar + arama kartı (tarih + lokasyon)
• Araç listeleme: Marka, fiyat, yakıt, vites, lokasyon filtreleri
• Araç detay: Galeri + özellikler + fiyat hesaplama
• 5 adımlı rezervasyon akışı:
    1. Alış/iade lokasyonu ve tarih
    2. Güvence (sigorta) paketi seçimi
    3. Ek ürünler (çocuk koltuğu, ek sürücü, vs.)
    4. Sürücü bilgileri + TC kimlik doğrulama
    5. Online ödeme (Iyzico Sanal POS) veya ofiste ödeme
• Üyelik sistemi: Kayıt + giriş + şifremi unuttum
• Müşteri paneli: Rezervasyonlarım, iptal, profil bilgileri
• Otomatik e-posta bildirimleri (rezervasyon onay, hatırlatma)
• SEO uyumlu: Google'da bulunabilirlik için optimize

────────────────────────────────────────────────
B. ADMİN PANELİ (FİRMA TARAFI)
────────────────────────────────────────────────

• Dashboard: Günlük gelir, aktif kiralamalar, müşteri sayısı, grafikler
• Araç yönetimi: CRUD, fotoğraf yükleme, durum takibi
  (müsait/kirada/bakımda)
• Şube yönetimi: Multi-lokasyon
• Filo takibi: Hangi araç hangi şubede, doluluk oranı
• Marka yönetimi
• Müşteri yönetimi
• Rezervasyon yönetimi: Onay, iptal, tamamlama
• Dinamik fiyatlandırma modülü:
    - Sezonluk fiyat (yaz/kış/bayram)
    - Kampanya/indirim kuponları
    - Erken rezervasyon indirimi
    - Hafta sonu farklı fiyat
• Raporlama: En çok kiralanan araç, gelir grafiği, Excel export
• Rol bazlı yetkilendirme: Admin, Şube Müdürü, Personel

────────────────────────────────────────────────
C. TEKNİK ALTYAPI
────────────────────────────────────────────────

• Backend: ASP.NET Core 9 (REST API)
• Frontend: Angular 20 (modern, performanslı SPA)
• Veritabanı: MS SQL Server (migration süreçleri dahil)
• Mimari: Clean / Layered Architecture
• Güvenlik: JWT + HttpOnly Cookie, BCrypt şifreleme
• Logging: Serilog (hata ve aktivite takibi)
• API dokümantasyonu: Swagger
• Performans: Hız optimizasyonları (lazy loading, image CDN)
• Yedekleme: Günlük otomatik DB yedek
• SSL/HTTPS: Hazır kurulum
• Iyzico Sanal POS entegrasyonu (3D Secure dahil)
